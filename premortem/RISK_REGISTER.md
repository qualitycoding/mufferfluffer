# Risk register

The register is kept in one place, `plan/RISKS.md` (R-001 to R-020), so that the implementer reads a single table. Risks R-016 to R-019 came from the pre-mortem rounds and R-020 from the assumption audit; each round's file in this directory lists its failure modes with lens, severity, likelihood, root cause, trace and the planner's disposition.
