# Changelog

## 0.1.0

First version.

- A shared C++17 DSP core with seven effects: Fluff Lowpass, Fluff Ring, Fluff Phase, Fluff Delay, Fluff Bank, Fluff Osc and Fluff Swarm.
- Seven VST3 plug-ins (version 0.1.0) with a generic editor, built with JUCE 9.0.5.
- A VCV Rack 2 plug-in (version 2.0.0) with seven modules and their own panels.
- User guide in `docs/USER_GUIDE.md`.
- Continuous integration on Linux, Windows and macOS, including sanitiser builds, plug-in validation with pluginval and dependency advisory scans.
