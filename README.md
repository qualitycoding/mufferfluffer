# mufferfluffer

Original software effects inspired by a well-known family of analogue effect pedals, delivered as
VST3 plug-ins and as a VCV Rack 2 plug-in that share one DSP core.

This is a personal, non-commercial hobby project. It is not affiliated with, endorsed by or derived
from the code, presets or artwork of any pedal or plug-in manufacturer.

Status: planning. The execution plan lives on a `gen-*` branch (see `HANDOFF.md` there).
