# Listening demos for gate G-LISTEN

Rendered from commit e38a9b010b86e028eae60e5e25305650fbe0f33c of qualitycoding/mufferfluffer by the workflow `evidence.yml`
(run https://github.com/qualitycoding/mufferfluffer/actions/runs/44468626667).

Every file on this branch is this project's own work: the dry inputs are synthesised by
`tools/make_demo_inputs.py` and processed by this project's effects, with no third-party recording.
The files are licensed under the repository licence, AGPL-3.0-only (see `LICENSE`).

`INDEX.md` lists each demo's effect, settings, processed-section peak before normalisation and the gain
applied; `SHA256SUMS` holds the checksums of the 23 WAV files. Each demo starts with three seconds of
the unprocessed input.
